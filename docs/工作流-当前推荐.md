# 去 AI 味写稿工作流：当前推荐版

- 版本：2026-11-13，依据四轮盲审（评审：Ada 一人）
- 用法：[writer/README.md](../writer/README.md)
- 这是通用工作流。台词、科普、训练只是拿来检验的样例，不针对任何一个场景、题目或提示词。

## 一句话

**把 brief 写对，比选模型和加 skill 都重要。** brief 只写场景和事实，不写风格要求和强调，不能出现的内容不给写稿模型看。写稿模型用 Gemini 4 Argon，加 scene-anchored，一次写 3 份，检查后由人挑。

## 流程

```
brief  ──检查──▶  缺必填项：退回；有风格要求、强调：提示
  │
写稿    Gemini 4 Argon + scene-anchored，写 3 份（看不到 check_only）
  │
检查    不过：出现不能出现的说法 / 事实数字没写对
        提示：多出来的数字、长度、brief 回声、口语化、感叹句、碎句、口令、AI 腔句式
  │
人挑    按报告看，选一份；都不行就改 brief 再跑
```

不自动改稿。前几轮评测只验证了写稿这一步，“检测后改写”还没有评测过，所以先不放进流程。

## 每一步的依据

| 决定 | 依据 |
|---|---|
| brief 只写事实和场景，不写风格要求 | 第一轮 brief 写了“要短”“制造紧张感”，所有模型、所有组合都写成碎句加感叹号（268 句台词里，37% 不到 5 个字，54% 带感叹号） |
| 不能出现的内容不给写稿模型看 | 第三轮 brief 写了“不能用左右脑失衡来解释”，15 份稿子全部提到“左右脑”，还有一份编出“你刚才问……”。第四轮把它藏起来后：旧 brief 质量 2.0，新 brief 2.83，痕迹归零 |
| 每件事只写一次，不加强调 | 第三轮 brief 强调了“对面”，每份稿子都重复 1–6 次 |
| speaker 写清身份、场合、关系，不写语气 | 第三轮科普里“咱们”泛滥（Gemini 8/9），Ada 指出专业场合应该说“我们”；第四轮还出现了“教官”带出部队腔 |
| 模型：Gemini 4 Argon | 第一、三轮台词第一（4.00、4.33），第三轮科普与 GLM 并列（3.00）；每份约半美分，比 Kimi 便宜约 8 倍，效果也不比 Kimi 差 |
| skill：scene-anchored | 四轮里没有哪种 skill 组合稳定比不加好（差距都在 0.5 分以内）。scene-anchored 质量和不加打平，但能把口语腔和提示词痕迹压到 0 |
| 不用 stop-slop | 三轮都垫底（第一轮科普 2.67，第三轮 Gemini 2.33） |
| 写 3 份由人挑 | 同一配置写两次，分差可以达到 1–2 分；检查能筛掉硬错误，但判断不了写得好不好 |

## 通用规则（scene-anchored 的核心，也是看稿标准）

**每句话都要能追溯到这个场景：这个听话人、这件事、这个时刻。** 追溯不到的句子分两类：

1. 提示词的痕迹：写了不让写的、把强调过的内容反复说、照字面执行风格词、编出对方没提过的问题。
2. 放到哪篇稿子里都成立的句子：寒暄、安抚、套近乎、空泛的鼓励、万能的开头和收尾、对旁观者交代情况。

说话的分寸也由场景决定：用词、人称、多口语还是多正式，由说话人的身份、场合、与对方的关系决定。像人说话不等于说得随意。

## 还不确定的

- **评审只有一个人，每个组合只有 3–6 份稿子。** 现在的“推荐”是方向一致，还不是可靠的结论。要定下来，需要再找几个人评，或者每个组合多写几份。
- **训练线（带练口令）用什么组合都只有 2–3 分。** 原因还没找到，可能是“按秒写口令”这种格式本身的问题，也可能是缺少带练方面的专业知识。用这个工作流写训练口令，要人工重写。
- **检测指标的阈值都还没有校准**，只用来提示，不作为判断标准。
- **“检测后自动改写”还没有评测过。** 代码在 `pipeline/` 里，但还没接进推荐流程。

## 怎么继续改进

每改一项（brief 写法、模型、skill），都跑一轮盲审再定：

1. `eval/arms/*.json` 写参赛组合，用 `python eval/scripts/sample_pack.py` 生成稿子（`--samples` 控制每个组合写几份）。
2. `python eval/scripts/build_review_artifact.py --run <目录>` 生成审稿文件 `<目录>/<名字>-盲审.html`，发给评审，双击就能评。
3. 评审交回的结果文件放进 `<目录>/ratings/`，再用 `python eval/scripts/reveal.py --run <目录>` 揭晓。
