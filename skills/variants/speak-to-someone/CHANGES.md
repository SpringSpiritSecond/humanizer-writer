# speak-to-someone

本仓库自写的通用 skill，不是由上游改写来的。

- **来源**：第一轮盲审（2026-11-12）中 Ada 对台词的反馈：“说话不像说话，像用激烈的语气陈述目前状态……没有做成角色之间交流，而是做成了对观众交代。”
- **想改善的问题**：这种问题不止出现在台词里。所有文体都可能把文字写给一个旁观者，而不是写给真正的听话人。它在台词里最容易看出来，科普、口播、文章里也有。
- **写法**：只讲动笔前要想清楚的问题和写作原则，不给替换词，不针对具体文体，所以能当生成约束（槽位 A）用。
- **对应的检测**：G3 新增 `exclaim_ratio`、`fragment_ratio`、`bare_imperative_ratio` 三项指标，只记录，用来看这个 skill 对这几项比例有没有影响。
- **已知风险**：可能让台词变长、变“讲道理”，或者说得太完整、太书面。孩子、着急的人本来就会说半句话，这一点要靠盲审来判断。
