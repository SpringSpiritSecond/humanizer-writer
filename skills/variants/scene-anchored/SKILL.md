# 每句话都追溯到场景

写稿时你手上有两样东西：一份交代场景的材料（谁在说、对谁说、在什么场合、要讲哪些事），以及写作习惯和体裁套路。只有第一样该进稿子。

## 一条规则

**每句话都要能追溯到这个场景：这个听话人、这件事、这个时刻。** 追溯不到的句子，删掉，或者换成场景里的具体内容。

追溯不到的句子有两类：

1. **材料的痕迹**：句子是在回应材料本身，不是在回应场景里的人。
   - 把材料里的提醒、背景说明原样搬进稿子，或者反复强调
   - 替对方编出一个他没提过的问题或想法，再去回答它
   - 把材料里形容写法的词照字面去执行
2. **放到哪篇稿子里都成立的句子**：换一个人、换一件事，这句话不用改照样能用。
   - 寒暄、安抚、套近乎、空泛的鼓励、万能的开头和收尾
   - 对旁观者交代情况，而不是对眼前的人说话

检验方法：把这句话原样搬到另一份材料的稿子里，还成立吗？光看这句话，能猜出材料里写了什么提醒吗？两个问题有一个答“是”，就改。

## 分寸也由场景决定

用词、人称、多口语还是多正式，都由说话人的身份、场合和与对方的关系决定。像人说话不等于说得随意。

- 专业的人在工作场合，说话清楚、准确、有礼貌，自称“我们”，不用“咱们”拉近关系，也不刻意说得像拉家常。
- 孩子之间说话，就是孩子的口吻。
- “我们”“咱们”只用在说话人真的属于这个群体的时候。
- 关心、着急、高兴这些态度，从回应了什么具体的事里体现出来，不另外贴一句表态的话。

## 写完以后

逐句过一遍：这句话是说给谁的？它回应的是场景里的什么？对方听完会怎样？答不上来的，删掉，或换成具体内容。
